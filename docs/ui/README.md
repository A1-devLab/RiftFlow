# UI 설계

Figma 링크, 화면 그림, 사용자 흐름 문서를 이 폴더에서 관리합니다.

## 화면 후보

- 게임 전: 최근 전적, 사용자 요약, 챗봇
- 챔피언 선택: 성향 질문, 룬 후보 및 적용
- 게임 중: 경기 상태, 아이템 후보와 근거
- 게임 종료 후: 지표 분석, 시간대별 추천 복기

각 화면에서 필요한 입력 데이터와 사용자 동작을 함께 기록합니다.

notion : 대략적인 프로그램 구성 글

figma : 버튼, 텍스트 등 기초적인 ui 배치도
