# Data Dragon 형식 조사

rag 가 근거 자료로 쓰는 Data Dragon 의 형식을 필드 단위로 조사한 기록입니다.
Data Dragon 수집은 knowledge 담당의 몫이므로, 수집 대상을 정할 때 참고하도록 공유합니다.

- 기준: Data Dragon `16.18.1`, 언어 `ko_KR`, 조사일 2026-09-13
- 방법: 원본 파일을 받아 필드마다 실제 값을 셌습니다. 숫자는 모두 이 버전에서 센 값입니다.
- 한계: Data Dragon 과 패치 노트끼리만 대조했습니다. 실제 게임 안의 값, 경기 기록(MATCH-V5), 인게임 API 와는 대조하지 않았습니다.
  맨 아래 "확인하지 못한 것" 에 따로 적었습니다.

조사한 파일은 `api/versions.json`, `realms/kr.json`, `item.json`, `runesReforged.json`, `champion.json`, `champion/{id}.json`(173개), `summoner.json` 입니다.

## 한눈에 보기: 질문별로 쓸 수 있는 필드

| 룬 효과와 수치는? | `rune.longDesc` | 가능 | 62개 중 61개에 수치 있음 |
| **능력치 파편은?** | 없음 | **불가** | `runesReforged.json` 에 없음 |

| **승률, 픽률, 상성은?** | 없음 | **불가** | 통계 데이터가 아님 |

## 1. 버전과 지역

- `api/versions.json` 은 499개이고 최신이 첫 항목(`16.18.1`)입니다.
- 이 중 98개는 `x.y.z` 가 아니라 `lolpatch_7.20` 같은 옛 형식입니다. 버전을 숫자로 풀 때 걸러야 합니다.
- `realms/kr.json` 은 한국 서버 기준 파일별 버전을 줍니다. 조사 시점에는 `item`, `champion`, `summoner` 가 모두 `16.18.1` 이었습니다.
- 같은 파일의 `rune` 은 `7.23.1` 입니다. 옛 룬 체계의 버전이며, 지금 쓰는 `runesReforged.json` 은 이 목록에 없습니다.
- Data Dragon 버전(`16.18.1`)과 패치 노트의 패치 번호(`26.18`)는 번호 체계가 다릅니다.
  패치 노트의 바드 방어력(32, 레벨당 4.7)과 카시오페아 Q 피해량(65/100/135/170/205)이 `16.18.1` 값과 일치하는 것만 확인했습니다.

## 2. item.json

### 구조

- 최상위: `type`, `version`, `basic`, `data`, `groups`, `tree`. 아이템은 `data` 에 868개 있습니다.
- **`basic` 은 기본값 틀입니다.** 아이템에 키가 없으면 이 기본값을 뜻합니다.
  - `basic.stats` 는 능력치 키 65개를 전부 0 으로 가지고 있습니다.
  - `basic.gold` 는 `purchasable: false` 입니다.
  - `basic.maps` 는 `1, 8, 10, 12` 가 켜져 있습니다.
  - 그래서 아이템의 `stats` 에 없는 키는 0 이고, `into` 가 없는 아이템은 상위 아이템이 없는 것입니다.
- 모든 아이템에 있는 키: `name`, `description`, `colloq`(별칭), `plaintext`, `image`, `gold`, `tags`, `maps`, `stats`
- 일부에만 있는 키: `from` 348, `depth` 348, `inStore` 172, `into` 138, `effect` 103, `consumed` 100, `consumeOnFull` 52, `stacks` 46, `specialRecipe` 27, `hideFromAll` 9, `requiredChampion` 7

### ID 와 모드 사본

- ID 는 4자리 428개, 6자리 440개입니다.
- 6자리 ID 는 대부분 4자리 아이템 앞에 숫자 두 개를 붙인 사본입니다.
  예: `322065` 는 `2065`(슈렐리아의 군가) 앞에 `32` 를 붙인 것이고 이름도 같습니다.
  6자리 440개 중 279개가 이런 모양입니다. 나머지 161개(예: `663193`)는 이름이 같은 짝이 없습니다.

| 앞 두 자리 | 개수 | 켜진 맵 |
|---|---|---|
| `22` | 176 | 대부분 `30` |
| `77` | 162 | 대부분 `12`, `453` |
| `44` | 49 | 대부분 `30` |
| `32` | 26 | **`11` 만** |
| `66` | 16 | **`11` 만** |
| `55` | 7 | 없음 |
| `12` | 3 | `12` |
| `99` | 1 | `12` |

- **`32`, `66` 으로 시작하는 42개는 소환사의 협곡(`11`) 표시만 켜져 있습니다.** 맵 검사만으로는 걸러지지 않습니다.
- 맵 `30` 과 `453` 이 어느 모드인지는 확인하지 않았습니다.

### 협곡에서 살 수 있는가

협곡 표시가 켜진 4자리 아이템은 273개이고, 이 중에도 상점에서 사는 아이템이 아닌 것이 섞여 있습니다.

| 필드 | 협곡 4자리 | 뜻 (값을 보고 판단) |
|---|---|---|
| `gold.purchasable: false` | 55 | 살 수 없음 |
| `gold.total: 0` | 35 | 구조물 현상금, 칼리스타 창 같은 비상점 아이템 |
| `inStore: false` | 55 | 상점에 안 나옴 |
| `hideFromAll: true` | 5 | 목록에서 숨김. 예: `2421` 부서진 팔목 보호대 (초시계를 망가뜨리면 생김) |
| `requiredChampion` | 7 | 특정 챔피언 전용 |
| `consumed: true` | 18 | 소모품. 예: 강철의 영약 |
| `stacks` | 16 | 중첩 수 |

- 이름만으로 구분되지 않는 경우가 있습니다. 협곡 4자리 안에서도 새끼 화염발톱(`1101`, `1107`), 칼리스타의 칠흑의 창(`3599`, `3600`), 구조물 현상금(4개) 등이 이름이 겹칩니다.

### 가격과 조합

- `gold` 는 `base`, `total`, `sell`, `purchasable` 입니다.
- `total = base + 하위 재료 total 합` 입니다. 하위 재료가 있는 협곡 4자리 아이템 183개를 검산해 모두 맞았습니다.
- 재료가 없는 아이템은 `base` 와 `total` 이 같습니다(90개).
- `from` 은 하위 재료 ID 목록입니다. 같은 ID 가 두 번 나올 수 있습니다(`2421` 은 `1052` 두 개).
- `into` 는 상위 아이템 ID 목록입니다. 협곡 4자리 아이템의 `into` 에서
  - 6자리 사본을 가리키는 참조가 64건,
  - 협곡 표시가 없는 아이템을 가리키는 참조가 51건 있었습니다.
- `depth` 는 조합 단계로 보입니다(`2`, `3`). 재료가 없는 아이템에는 키가 없습니다.

`stats` 객체에 실제로 쓰인 키는 65개 중 12개뿐입니다.
설명문의 `<stats>` 줄마다 같은 값이 `stats` 에 있는지 대조했습니다 (조사 대상은 협곡, 4자리, 구매 가능, 500골드 이상 177개).

|---|---|---|
| 공격력, 체력, 주문력, 이동 속도, 방어력, 공격 속도, 마법 저항력, 마나, 생명력 흡수 | 모두 | 모두 있음 |
| 치명타 확률 | 17 | 16 (윤 탈 야생화살은 설명문에 `0%`, `stats` 에는 없음) |
| **스킬 가속** | 64 | **0** |
| **물리 관통력** | 12 | **0** |
| **기본 마나 재생** | 12 | **0** |
| **기본 체력 재생** | 8 | **0** |
| **마법 관통력** | 8 | **0** |
| **체력 회복 및 보호막** | 7 | **0** |
| **강인함** | 5 | **0** |

`basic.stats` 에 `FlatCritDamageMod`, `rPercentCooldownMod` 같은 키 자리는 있지만 값이 채워지지 않습니다.
**능력치는 `description` 을 근거로 써야 합니다.** 지금 fixture 의 `text` 는 설명문에서 만들므로 이 값들이 들어가 있습니다.

### 설명문 마크업

- 협곡 4자리 아이템 설명문의 태그: `br`, `attention`(수치), `mainText`, `stats`, `passive`, `active`, `keyword`, `magicDamage`, `physicalDamage` 등 약 40종
- `plaintext` 는 한 줄 요약이며 비어 있는 경우도 있습니다(예: 윤 탈 야생화살).
- 일부 아이템에는 `effect` 가 `{'Effect1Amount': '8', ...}` 처럼 문자열 값으로 있습니다. 어느 수치에 대응하는지는 따로 적혀 있지 않습니다.

## 3. runesReforged.json

- 트리 5개: 지배, 영감, 정밀, 결의, 마법. 트리 키는 `id`, `key`, `icon`, `name`, `slots` 입니다.
- 룬은 62개이고 키는 `id`, `key`, `icon`, `name`, `shortDesc`, `longDesc` 입니다.
- 슬롯별 룬 수: 정밀과 마법은 `[4, 3, 3, 3]`, 나머지는 `[3, 3, 3, 3]`. 첫 슬롯이 핵심 룬입니다.
- `longDesc` 에 수치가 있는 룬은 62개 중 61개입니다.
- 마크업이 섞여 있습니다: `lol-uikit-tooltipped-keyword`, `font color`, `<i>`(설정 문구, 13개), `b`, `hr` 등
- `shortDesc` 와 `longDesc` 가 같은 룬이 5개 있습니다.
- **능력치 파편(공격 속도 +10% 같은 것)은 이 파일에 없습니다.**

## 4. 챔피언

### 목록 파일 `champion.json`

- 173명. 키는 `version`, `id`, `key`, `name`, `title`, `blurb`, `info`, `image`, `tags`, `partype`, `stats` 입니다.
- `id` 는 영문 이름(`Aatrox`), `key` 는 숫자 문자열(`"266"`) 입니다.
- **`spells` 와 `passive` 가 없습니다.** 스킬 정보가 필요하면 상세 파일을 챔피언마다 받아야 합니다.

### 상세 파일 `champion/{id}.json`

- 목록의 키에 더해 `skins`, `lore`, `allytips`, `enemytips`, `spells`, `passive`, `recommended` 가 있습니다.
- 목록과 상세의 `tags`, `info`, `stats` 는 173명 모두 같았습니다.
- `recommended` 는 173명 모두 비어 있습니다.
- `allytips` 가 빈 챔피언 24명, `enemytips` 가 빈 챔피언 26명입니다.

### `info`, `tags`, `partype`

- `info` 는 `attack`, `defense`, `magic`, `difficulty` 점수입니다.
- **아크샨, 렐, 세라핀, 벡스는 `info` 가 난이도까지 전부 0 입니다.** 점수가 아니라 값이 비어 있는 것으로 봐야 합니다.
- `tags` 는 Mage 75, Fighter 60, Assassin 46, Tank 46, Support 43, Marksman 33 이고, 한 챔피언에 1~2개입니다.
  역할 분류이며 포지션이 아닙니다.
- `partype` 은 자원 이름입니다. 마나 145명, 기력·분노·없음 각 6명 등.
  **벨베스는 빈 문자열이고, 모데카이저는 `"보호막 "` 처럼 뒤에 공백이 붙어 있습니다.**
- `stats` 는 `hp`, `hpperlevel`, `armor`, `attackdamage`, `attackrange`, `movespeed` 등 20개 키입니다.

### 스킬 `spells`

스킬 692개(173명 × 4)를 셌습니다.

| 필드 | 결과 |
|---|---|
| `description` 에 숫자가 있음 | 72개 (10%) |
| `tooltip` 에 `{{ }}` 빈칸 표시가 있음 | **692개 (100%)** |
| `tooltip` 에서 빈칸을 뺀 뒤에도 숫자가 있음 | 342개 (49%) |
| `datavalues` 가 비어 있지 않음 | **0개** |
| `vars` 가 비어 있지 않음 | **0개** |
| `effect` 에 0 이 아닌 값이 있음 | 236개 (34%) |
| `cooldown` 이 전부 0 | 20개 (애쉬 Q, 카서스 Q, 신지드 Q 같은 토글·충전형) |
| `cost` 가 전부 0 | 124개 |

- **`tooltip` 의 빈칸(`{{ totaldamage }}` 등)을 채울 값이 파일 안에 없습니다.** `datavalues` 와 `vars` 가 전부 비어 있기 때문입니다.
- `effect` 는 챔피언마다 다릅니다. 카시오페아 Q 는 `[65, 100, 135, 170, 205]` 로 패치 노트와 일치했지만, 가렌 Q 는 전부 0 입니다.
- `costType`, `resource` 에도 빈칸 표시가 들어 있습니다(`{{ abilityresourcename }}` 등).
- `maxrank` 는 대부분 5(기본 스킬)와 3(궁극기)이고, 6·4·1 도 있습니다.
- 패시브 `description` 에 숫자가 있는 챔피언은 173명 중 39명입니다.

## 5. summoner.json

- 34개. 키는 `id`, `key`(숫자 문자열), `name`, `description`, `tooltip`, `cooldown`, `cooldownBurn`, `modes`, `summonerLevel` 등입니다.
- `modes` 에 `CLASSIC` 이 있는 주문은 9개입니다: 방어막, 정화, 점화, 탈진, 점멸, 유체화, 회복, 강타, 순간이동
- 9개 모두 `description` 에 숫자가 없고, 점멸을 뺀 8개는 `tooltip` 에 빈칸 표시가 있습니다.
- 쿨타임은 `cooldownBurn` 에 있습니다. 점멸 300, 강타 15, 점화 180 등입니다.

## 6. 현재 fixture 와 rag 에 미치는 영향

아직 고치지 않았습니다. 고칠지는 따로 정합니다.

| 발견 | 지금 상태 | 영향 |
|---|---|---|
| `item.stats` 가 불완전함 | 프롬프트는 설명문 기반 `text` 를 씀 | 낮음. `fields.stats` 를 근거로 쓰기 시작하면 틀린 답이 나옴 |
| 스킬 수치가 거의 없음 | fixture 는 `spell.description` 만 담음 | 스킬 피해량 질문은 근거 부족이 맞음 |
| 소환사 주문 없음 | fixture 에 `summoner.json` 없음 | 점멸·점화 질문은 근거 부족으로 나옴 |
| `hideFromAll` 아이템이 섞임 | 부서진 팔목 보호대가 fixture 에 있음 | 사는 아이템처럼 추천될 수 있음 |
| 소모품이 섞임 | 영약 3개가 fixture 에 있음 | 의도한 것인지 정해야 함 |
| 500골드 미만 재료가 없음 | `src/rag/README.md` 한계에 기록 | 조합 순서 질문에 약함 |
| `partype` 값 이상 | 벨베스 빈값, 모데카이저 끝 공백 | 프롬프트에 그대로 들어감 |
| `into` 에 다른 모드 참조 | 이름표에 없는 ID 는 프롬프트에서 뺌 | 해결됨 |

## 7. 확인하지 못한 것

- **실제 경기 기록에서 협곡 아이템이 4자리 ID 로 오는지.** fixture 는 4자리 ID 아이템만 담는데, 근거는 위의 사본 모양뿐입니다.
  6자리로 오는 협곡 아이템이 있으면 이 규칙을 고쳐야 합니다. 짝이 없는 161개도 사본이라는 근거 없이 빠져 있습니다.
- **`32`, `66` 으로 시작하는 협곡 표시 아이템 42개가 실제 협곡 상점에 있는지.** 이름이 4자리 아이템과 같은 것도 있고 다른 것도 있습니다.
- 맵 `30`, `453` 이 어느 모드인지.
- `effect` 배열이 실제 게임 수치와 맞는지. 카시오페아 Q 한 건만 패치 노트와 일치를 확인했습니다.
- `tooltip` 빈칸의 실제 값을 어디서 얻을 수 있는지.
- Data Dragon `16.18.1` 이 한국 서버 라이브와 같은지. 패치 노트 수치 두 건만 대조했습니다.
