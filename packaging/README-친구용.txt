RiftFlow 사용법
================

1. 압축을 푼 폴더에서 RiftFlow.exe 를 더블클릭합니다.

   처음 실행하면 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다.
   서명하지 않은 개인 제작 프로그램이라 뜨는 창입니다.
   "추가 정보"를 누른 뒤 "실행"을 누르세요.

2. 처음 켜면 1분 정도 게임 자료를 받습니다. 아래 상태 줄에 "업데이트 완료"가 나오면 끝입니다.

3. 롤 클라이언트를 켜고 로그인하면 전적이 자동으로 나옵니다.

4. 게임을 찾아 챔피언 선택 화면이 되면 RiftFlow가 "픽창" 화면으로 바뀝니다.
   챔피언을 올려놓고 2~3초 기다리면 룬을 추천하고, 롤 클라이언트에 "RiftFlow ..." 룬 페이지로 넣어 줍니다.
   직접 만든 룬 페이지는 건드리지 않습니다.
   룬 페이지 칸이 꽉 차 있으면 넣지 못하니, 쓰지 않는 페이지 하나를 지워 두세요.

5. 하고 싶은 플레이가 있으면 픽창 아래 칸에 말로 적으세요.
   예: "공격적으로 하고 싶어, 룬 다시 짜줘"

6. 게임이 시작되면 "인게임" 화면으로 바뀌고, 끝나면 전적 화면으로 돌아옵니다.

문제가 생기면 화면을 캡처해서 보내 주세요.
